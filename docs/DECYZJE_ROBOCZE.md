# Decyzje robocze V12

- Produkt Halloween; folder i API NOCTURNE zachowane. Kontynuacja geometrii i kodu, własny raster trójkątów WebGL2 zamiast wymiany projektu na Three.js. Końcowe ASCII i awaryjny CPU zachowane.
- Źródła przeniesione do `src/`, powtarzalny builder do `tools/build.py`. Work poza paczką to historia/kompatybilny wywoływacz, nie aktualne moduły.
- Najnowszy kanon V12 wygrywa ze starym końcem po quizie, rozdzielnym wyborem zwierząt i starymi epitafiami. Wszystkie ofiary kontynuują kampanię.
- Automatyczny resolver: E2 przy porażce Areny; po Tomie E3 → E6 → E4 → E7 → E5 → E1. To wdrożona, odwracalna propozycja V10, nie nowa autorska aprobata kolizji flag. Warunki są w JCONFIG/jResolve. Brak menu numerów endingów.
- E6 realizuje zaproponowaną pustą kopię świata. Szczegół pozostaje interpretacją roboczą. Nieufność/uraza uruchamiają go według propozycji, a nie zatwierdzonego nowego dialogu autora. Informacje o roboczości pozostają w dokumentacji, nie w kwestiach postaci.
- Nowi wrogowie uczą walki w korytarzu po Goon Roomie, zamiast przeszkadzać w pierwszych scenach Mściciela. Układ, statystyki broni/pancerza i liczby HP są do balansu. Nie dodano nowych żywych ludzi do fabuły.
- Ranny umiera mimo nożyc; szybka pomoc daje wskazówkę. Przemoc niedosłowna, bez odsłoniętej anatomii, graficznego samouszkodzenia lub samobójstwa; czerwony ślad na papierze, błysk/upadek i ubrania zachowują sens scen.
- Okno wspólnego potwierdzenia secretu: 3 s, pozwala na kolejne klawisze przy ograniczeniach sprzętu. Faza C ma wolne fale i ruch w osi W/S/↑/↓; A/D i ←/→ nadal ustawiają mechanizm. Porażka powtarza etap.
- Mikrofon opcjonalny i lokalny. Karaoke mierzy rytm/głośność, nie rozpoznaje słów. Bez zgody ta sama punktacja z klawiatury. Brak pliku Rema nie blokuje gry; jest dźwięk zastępczy.
- Artefakty prywatne, osobne bronie/pancerze, nożyce wspólne. Gesty bez HP i bez wpływu na reputację/ending. Zapis v2 zachowuje klucz v1 dla migracji; callbacków nie serializujemy. Metapostęp i ustawienia są osobne.
- Wyniki FPS odnoszą się do lokalnego Edge, a nie wszystkich laptopów. Fizyczny ghosting/słyszalność wymagają człowieka i sprzętu; automatyzacja sprawdza odebrane zdarzenia. Telefon wyłączony z testów na polecenie użytkownika.
