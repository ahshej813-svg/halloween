# Decyzje robocze

- Folder NOCTURNE i debug API pozostają dla zgodności; tytuł produktu Halloween.
- V12 nadpisuje wcześniejsze niezależne zwierzęta. Rozbieżność pozostawia oba wybory edytowalne; dopiero zgodność zamyka wybór i zapisuje jedno animal.
- Priorytet E3/E4/E6 i pusty świat E6 są propozycjami. Przy implementacji resolvera trzymać je w konfigurowalnych danych i opisać, nie przedstawiać jako zatwierdzony kanon.
- Elementy fabularne niegotowe są jawnie opisane w STATUS. Nie zastępować walk i minigier samymi terminalowymi przyciskami ani debug-przeskokami.
