# HALLOWEEN — KOMPLETNY PAKIET WYKONAWCZY DLA CODEXA, v12

**Cel:** załącz ten ZIP do istniejącego projektu gry, otwórz repozytorium w Codexie, a następnie wklej zawartość `01_JEDEN_PROMPT_DO_CODEXA.txt`.

Ta paczka zawiera **dokumentację i mapy, NIE kod gry**. Poprzedni asystent nie otrzymał plików gry; dlatego Codex musi najpierw obejrzeć i uruchomić prawdziwe repo. Dokumentacja nie potwierdza ani działającej gry, ani przetestowanych FPS.

## Kolejność źródeł przy sprzecznościach

2. `03_KONTEKST_ROZMOWY_v12.md` — pełne uporządkowane ustalenia z bieżącego czatu.
3. `SCENARIUSZ/HALLOWEEN_SCENARIUSZ_V8.md` — sceny i kwestie, **z nadpisaniami z v12**.
4. `ENDINGI/HALLOWEEN_WARUNKI_AUTOMATYCZNE_v10.md` — automatyczne zakończenia bez menu; szczegółowy priorytet E3/E4/E6 wciąż projektowy.
5. `MAPA_V11/HALLOWEEN_SWIAT_WALKA_I_MAPA_v11.md` — świat i moby, nowe wyposażenie w znacznej części propozycjami.
6. `DIALOGI/HALLOWEEN_DODATEK_v6_ASCII_MSCICIEL_DIALOGI.md` — dialogi, nagrobki, widoczność Mściciela.
7. `TECH/HALLOWEEN_SPEC_v5_Codex.md` oraz `TECH/SPEC_NADRZEDNA_v7.md` — szczegółowe wymagania silnika, walki i testowania; starsze zapisy nie są nadrzędne.
